ai文字 Windows 便携版 v1.3.1

1. 把整个 ZIP 解压到一个文件夹，再双击 ai文字.exe。
2. 程序自动打开浏览器写作台，无需安装 Python，也无需管理员权限。
3. 展开“模型与服务商设置”，选择服务商、API 地址和模型，填写对应平台的 API Key。
4. 支持连接检查时可先测试；GLM、MiniMax 和火山方舟按提示用短任务直接生成验证。
5. 填写写作要求，第一次选择“直接生成”；完成后复制或下载稿件。
6. 可命名并保存配置，方便切换；Key 默认不保存，勾选后会明文存储在本机浏览器中。
7. 服务运行时请保留启动器窗口。关闭浏览器不会停止服务；在启动器点击“停止并退出”。

默认页面：http://127.0.0.1:8765/
浏览器未自动打开时，点击启动器里的“打开写作台”，或手动打开上面地址。
重复双击会打开已有同版本写作台，不重复启动后台。
若提示端口占用，请先下载稿件，再关闭旧版的启动窗口；新版不会自动停止旧服务。
其他端口可通过命令行指定：ai文字.exe --port 8766
更换端口或浏览器后，已保存的配置和用量不会共享。

配置和用量保存在本机浏览器；作品不会自动保存，请下载后再退出。
EXE 中的模型预设和提示词已内置。更新程序时替换 EXE，不需移动浏览器中的设置。
适用于 Windows 10/11 x64。本发布未进行代码签名。
实际模型调用需要网络、对应平台的 API Key，并按该平台计费。
